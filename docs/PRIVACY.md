# TeXslate – Datenschutzerklärung / Privacy Policy

*Stand / Last updated: 2026-09-03*

## Deutsch

**Kurzfassung: TeXslate sammelt keine Daten.**

- **Keine Datenerhebung:** TeXslate enthält keine Werbung, keine Analyse-/Tracking-Dienste
  und legt keine Benutzerkonten an. Es werden keine personenbezogenen Daten an den
  App-Anbieter übertragen.
- **Lokale Verarbeitung:** Dokumente, Projekte und Einstellungen liegen ausschließlich
  auf dem Gerät. Der LaTeX-Compiler läuft vollständig offline auf dem Gerät.
- **TeX-Bundle-Download:** Beim ersten Kompilieren lädt der eingebaute Compiler (Tectonic)
  einmalig frei verfügbare TeX-Ressourcen (Makro-/Schriftdateien) von den offiziellen
  Tectonic-Servern. Dabei werden keine Dokumentinhalte übertragen.
- **Optionaler KI-Assistent (standardmäßig aus):** Aktiviert man den KI-Assistenten und
  bestätigt eine Anfrage im Vorschau-Dialog, wird der dort angezeigte Text (Frage und –
  falls gewählt – markierter Code oder das Dokument) direkt an den vom Nutzer gewählten
  Anbieter gesendet: Anthropic, OpenAI oder Google. Dafür gilt die Datenschutzerklärung
  des jeweiligen Anbieters. Der API-Key stammt vom Nutzer und wird ausschließlich lokal,
  verschlüsselt über den Android-Keystore, gespeichert. Ohne ausdrückliche Bestätigung
  verlässt kein Text das Gerät.
- **Berechtigungen:** INTERNET wird nur für die beiden oben genannten Zwecke genutzt.
- **Kontakt:** thomas@bgg-mail.de

## English

**In short: TeXslate collects no data.**

- **No data collection:** TeXslate contains no ads, no analytics or tracking, and no user
  accounts. No personal data is transmitted to the app provider.
- **Local processing:** Documents, projects and settings stay on the device. The LaTeX
  compiler runs fully offline on the device.
- **TeX bundle download:** On first compile, the built-in compiler (Tectonic) downloads
  freely available TeX resources (macro/font files) once from the official Tectonic
  servers. No document content is transmitted.
- **Optional AI assistant (off by default):** If the user enables the AI assistant and
  confirms a request in the preview dialog, the text shown there (the question and — if
  selected — the highlighted code or the document) is sent directly to the provider the
  user chose: Anthropic, OpenAI or Google. That provider's privacy policy applies. The
  API key is supplied by the user and stored only locally, encrypted via the Android
  Keystore. No text leaves the device without explicit confirmation.
- **Permissions:** INTERNET is used only for the two purposes above.
